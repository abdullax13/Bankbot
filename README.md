# Discord Bank Bot (Arabic) - جاهز لـ Railway + GitHub

بوت لعبة بنك بسيط بأوامر عربية مثل الصورة (راتب، بخشيش، حظ، روليت… إلخ) مع رد بصورة لكل أمر.

## المتطلبات
- Node.js 18+
- إنشاء بوت في Discord Developer Portal وإضافة البوت للسيرفر.

## التشغيل محلياً
1) انسخ `.env.example` إلى `.env`
2) حط المتغيرات:
- `DISCORD_TOKEN`
- `PREFIX` (مثلاً `!`)

3) شغّل:
```bash
npm install
npm start
```

## Railway (Deploy from GitHub)
1) ارفع الملفات كاملة على GitHub (زي ما هي).
2) في Railway: New Project -> Deploy from GitHub Repo
3) في Variables (Environment):
- `DISCORD_TOKEN`
- `PREFIX` (اختياري)
- `OWNER_ID` (اختياري)

Railway راح يشغّل `npm start` تلقائياً.

## الأوامر
اكتب الأوامر في الشات مع الـ Prefix:
- `!راتب`
- `!بخشيش`
- `!حظ`
- `!روليت <مبلغ>`
- `!نهب @user`
- `!رهان <مبلغ>`
- `!استثمار <مبلغ>`
- `!تداول <مبلغ>`
- `!قمار <مبلغ>`
- `!نرد <مبلغ>`
- `!لعبه` (تخمين رقم)
- `!لون` (اختيار لون)
- `!فواكه <مبلغ>`
- `!تسريع <مبلغ>`
- `!شراء <item>`
- `!بيع <item>`

## ملاحظة عن التخزين
الاقتصاد محفوظ بقاعدة بيانات SQLite داخل الملف `data/bank.sqlite`.
إذا سويت إعادة نشر/حذف السيرفر ممكن يتصفّر حسب إعدادات الاستضافة.
